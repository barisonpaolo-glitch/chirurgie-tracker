Chirurgie Tracker PRO (2025 + 2026)
==================================

Questa è una mini-app web “tipo app” (PWA) pensata per smartphone.
- Dati: 2025 importato (già compilato) + 2026 pronto
- Salvataggio: offline sul dispositivo (localStorage)
- Export: Excel .xls (compatibile)

Avvio veloce (PC):
- Apri index.html con Chrome/Edge.

Per installarla come app (consigliato, smartphone):
- Serve via http(s), ad esempio:
  python -m http.server 8000
- Dal telefono apri: http://IP_DEL_PC:8000
- Poi “Aggiungi a schermata Home”.

Per spostare i dati su un altro device:
- Esporta backup (JSON) e poi Importa backup.
